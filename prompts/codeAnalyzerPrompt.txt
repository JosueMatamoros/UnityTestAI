TASK:

1. METHOD SUMMARY — Extract:
   - Method signature (name, parameters, return type)
   - All inputs with their names and types
   - Return type

2. DECISION TABLE — Scan the method body line by line:
   - `if` / `else if` → add TWO rows (one true, one false)
   - `foreach` / `for` / `while` → add ONE entry to loops
   - CRITICAL: an `if` INSIDE a loop is a separate condition — TWO rows of its own
   - Include a fall-through row when ALL conditions fail (e.g., "throws exception")

3. LOOPS — List every `foreach`, `for`, `while`:
   - For `foreach`: condition = collection being iterated
   - For `for`/`while`: condition = loop condition expression

4. SIDE EFFECTS — Detect:
   - State changes, field mutations, external calls, property sets, thrown exceptions

5. DEPENDENCIES — External project-specific types the method interacts with:
   - Fields/arrays of the SAME class are NOT dependencies — they are internal state
   - For each: list only the members the target method calls on it

6. PRIVATE MEMBERS — This section is CRITICAL for test generation.

   Scan ALL of the following in class `<class-name>` and fill privateMembers:

   A. Fields without `public` access modifier that the target method reads or writes:
      kind = "field"
      Example: `private Queue<Vector3> waypoints` → { name: "waypoints", kind: "field", type: "Queue<Vector3>" }

   B. Properties without `public` that the target method reads or writes:
      kind = "property"

   C. Nested types (enum, struct, class) declared INSIDE `<class-name>` without `public`:
      kind = "nestedType"
      List ALL values if it is an enum.
      Example: `enum State { Wait, Init }` → { name: "State", kind: "nestedType", type: "enum", nestedValues: ["Wait","Init"] }

   D. Unity MonoBehaviour message methods if `<method-name>` IS one of them:
      These are ALWAYS considered private regardless of their declaration:
      Update, FixedUpdate, LateUpdate, Awake, Start, OnEnable, OnDisable,
      OnTriggerEnter2D, OnTriggerExit2D, OnCollisionEnter2D, OnCollisionExit2D,
      OnTriggerEnter, OnTriggerExit, OnCollisionEnter, OnCollisionExit, OnDestroy
      kind = "unityMessage"
      Example: `void FixedUpdate()` → { name: "FixedUpdate", kind: "unityMessage", type: "void" }

   RULES for privateMembers:
   - In C#, a member with NO access modifier defaults to `private`
   - Include a field if the target method body references it (reads, writes, calls methods on it)
   - Do NOT include public members
   - If there are no private members, return []

7. START/AWAKE FIELDS — Scan Start() and Awake() in the context.
   List every field initialized (assigned, newed, or fetched) inside Start() or Awake()
